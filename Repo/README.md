# Fine-Tuned Model Evaluation

This repository contains the code and notebooks used to evaluate a fine-tuned embedding model against the base model on BOQ document retrieval.

## Project structure

- notebooks/: evaluation and production notebooks
- training_meta.json: metadata for the fine-tuned model
- requirements.txt: Python dependencies

## Notes

- The repository is prepared for GitHub push without including the large BOQ PDF corpus and generated artifacts.
- The notebooks are intended to be run in a Python environment with the packages listed in requirements.txt.
